Публичный сайт «Исследовательские проекты по современной математике» школы 179 на 2026/27 год, адрес `d1-d57.github.io/projects`. `stranica/index.html` — самодостаточная страница без внешних библиотек: как устроен год (знакомство с руководителями 12–26 сентября, выбор темы, две предзащиты, защита в мае), какая задача годится для проекта, карточки руководителей с темами и записями выступлений. `stranica/temy.json` — источник карточек: 16 руководителей и 25 тем, по пять в геометрии, комбинаторике, топологии и алгебре. `stranica/shkolniki.js` — анкета «Записаться на проект».

Страницу читают десятиклассники, чтобы выбрать руководителя и тему, и научные руководители, чтобы понять, как устроен год и какая нужна задача. Здесь страницу не правят: её собирает `stranica/build.py` в `matproekty-179`, сюда файлы копируются, и GitHub Pages публикует их после push в `main`. Форма шлёт заявку в `ankety`, а Telegram-бот читает тот же `temy.json` прямо с этого сайта.

Страница опубликована 29.08.2026 как приглашение научным руководителям. 18.09 её развернули на набор школьников: анкету руководителя убрали, появилась анкета школьника; это последняя правка. README отстал: он описывает старую анкету руководителя и файлы, которых в дереве уже нет.

Сюда идти, чтобы посмотреть, что видят школьники и руководители, или выложить обновлённую страницу. Всё содержательное — в `matproekty-179` (генератор, темы, набор, переписка), приём заявок — в `ankety`.

# matproekty-179-stranica

Публичный репозиторий ровно с одной вещью: страница-приглашение научным руководителям
математических проектов 179 школы, вместе со встроенной анкетой.

Адрес страницы: https://d1-d57.github.io/projects/

## Что здесь лежит и чего здесь нет

Здесь — только то, что должно быть публичным: `stranica/index.html`, `stranica/anketa.js`,
`stranica/anketa.css` и workflow публикации. Рабочий репозиторий проекта (`matproekty-179`)
приватный и сюда не копируется целиком: в нём внутренние материалы, которым в открытом
доступе не место.

## Как обновить страницу

Файлы правятся в приватном `matproekty-179`, сюда переносятся копированием:

```bash
cp ~/Documents/GitHub/matproekty-179/stranica/{index.html,anketa.js,anketa.css} \
   ~/Documents/GitHub/matproekty-179-stranica/stranica/
cd ~/Documents/GitHub/matproekty-179-stranica && git add -A && git commit -m "страница: обновление" && git push
```

Публикация после `push` в `main` идёт сама, workflow `pages`; сайт — содержимое `stranica/`.

## Анкета

Форма шлёт `POST` на Cloudflare Worker `https://ankety-worker.ankety.workers.dev/submit`,
`form_id` = `nauchruki-2026`; ответы лежат в базе D1 `ankety-db`. Секретов в этом
репозитории нет и быть не должно: всё, что здесь, публично по определению.
